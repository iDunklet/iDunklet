## 🚀 Featured Projects

### 📋 [TaskFlow API — Java & Spring Boot](https://github.com/iDunklet/taskflow-api)

A RESTful task management API built using Java, Spring Boot and PostgreSQL.

**Technologies:** Java 21 · Spring Boot · Spring Data JPA · PostgreSQL · Docker · Maven

**Features:**
- CRUD operations for task management.
- Layered architecture with controllers, services and repositories.
- PostgreSQL database integration.
- RESTful endpoints with HTTP status handling.
- API testing with Postman.

### ☁️ [TaskFlow Serverless — TypeScript & AWS](https://github.com/iDunklet/taskflow-serverless)

A task management REST API built with TypeScript, Node.js and Express, designed to evolve into a serverless application on AWS.

**Current technologies:** TypeScript · Node.js · Express

**Features:**
- REST API with GET, POST, PUT and DELETE endpoints.
- Layered architecture.
- Request validation and HTTP error handling.
- API testing with Postman.
- In-memory task storage.

**Next steps:** DynamoDB integration, AWS Lambda deployment and API Gateway configuration.
